Privacy

Race Day Copilot has no accounts, no sign-up, no advertising and no tracking cookies. This page says what actually happens to data rather than what would be legally permissible.

What this page is

This page is a static description of a tool that runs on your own computer. It is served by GitHub Pages and contains no scripts that send anything anywhere.

What is collected

Nothing. This page has no forms, no analytics, no cookies and no server of its own. The tool it describes runs locally on your machine, and anything it processes stays there unless you yourself configure it to call an external model.

Third parties

  • GitHub Pages. Serves this page. It records standard web request logs, including your IP address.

Fonts are served from this site, so no font provider is contacted and no content delivery network is involved. There is no analytics provider of any kind.

Children

This project is aimed at adults and students in higher education. It is not directed at children under 13 and collects nothing that would identify one.
